Honest measurement notes

Android does not expose a simple "current FPS" number for games. This tool reads the frame timings Android records for the game process (best effort) plus battery temperature and the thermal throttling state - the things that actually decide your sustained FPS. For the most reliable before/after: play one match, run Measure, optimize, restart the game, play another match, run Measure again.

FF Mobile Optimizer 1.0.0 - Android settings only. The game itself was never modified, so there is no ban risk.
